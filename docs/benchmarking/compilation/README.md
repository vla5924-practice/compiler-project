# Производительность компиляции

Были поставлены и достигнуты следующие цели:

1.  Реализована система для генерации входных файлов для лексического и
    синтаксического анализаторов.
2.  Реализованы лексический и синтаксический анализаторы при помощи
    генераторов flex, bison.
3.  Реализована система для запуска лексических и синтаксических
    анализаторов и агрегации времени их работы.
