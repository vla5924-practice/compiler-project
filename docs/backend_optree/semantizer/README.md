# Семантический анализатор

Семантический анализатор – компонент для проверки структурной и
типизированной корректности различных операций в дереве.
Механизм анализа обеспечит выявление и предотвращение потенциальных
ошибок, возникающих при преобразовании исходного кода в промежуточное
представление.
